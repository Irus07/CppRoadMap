# 01. Контейнеры STL: Производительность и устройство памяти

> Стандартная библиотека шаблонов (STL) спроектирована по принципу **Zero-Cost Abstractions**: вы не платите производительностью за использование удобных высокоуровневых контейнеров по сравнению с низкоуровневым C-кодом.

---

## 1. `std::vector<T>`: Абсолютный король контейнеров

В 95% задач в C++ следует использовать `std::vector`.

### Внутреннее устройство:
Вектор состоит ровно из трёх указателей (24 байта на x64):
1. `begin` — начало выделенного буфера в куче.
2. `end` — конец текущих данных (определяет `size()`).
3. `capacity_end` — конец выделенной памяти (определяет `capacity()`).

```
Вектор на стеке (24 байта) ----> [ E1 | E2 | E3 | ..свободно.. ] (в куче)
                                  ^              ^              ^
                                begin           end         capacity_end
```

### Почему вектор быстрее списков и деревьев?
* **Кэш-локальность (Cache Locality):** Элементы лежат последовательно. Процессор загружает их в L1/L2 кэш линиями по 64 байта сразу пачками.
* Связные списки (`std::list` / `LinkedList<T>`) разбрасывают ноды по случайным адресам кучи, вызывая постоянные кэш-промахи (Cache Misses).

### Оптимизации при работе с вектором:
```cpp
std::vector<int> v;

// 1. Всегда используйте reserve(), если размер известен заранее:
v.reserve(1000); // Выделяет память ОДИН РАЗ, предотвращая 10 лишних реаллокаций!

// 2. emplace_back() вместо push_back():
struct Player { Player(std::string name, int score); };
std::vector<Player> team;

// push_back создает временный объект и перемещает его:
team.push_back(Player("Alice", 100)); 

// emplace_back конструирует объект ПРЯМО внутри памяти вектора без временных копий:
team.emplace_back("Bob", 200); 
```

## 2. `std::unordered_map` vs `std::map`

| Характеристика | `std::unordered_map<K, V>` | `std::map<K, V>` |
| :--- | :--- | :--- |
| **Аналог в C#** | `Dictionary<TKey, TValue>` | `SortedDictionary<TKey, TValue>` |
| **Структура под капотом** | Хеш-таблица (цепочки бакетов) | Сбалансированное красно-чёрное дерево |
| **Сложность поиска** | $O(1)$ в среднем | $O(\log N)$ всегда |
| **Порядок элементов** | Случайный / непредсказуемый | Строго отсортирован по ключу |
| **Требования к ключу** | `std::hash<K>` и `operator==` | `operator<` (или компаратор) |

> **Подводный камень `operator[]`:** 
> В C++ вызов `map["unknown_key"]` **не бросает исключение**, а молча создаёт элемент со значением по умолчанию! Если вы хотите просто проверить наличие ключа, используйте `.contains()` (C++20) или `.find()`.

## 3. `std::string` и Small String Optimization (SSO)

Строки в C++ мутабельны (в отличие от immutable строк в C#).

### Магия SSO (Оптимизация коротких строк):
В современных реализациях STL (MSVC, Clang libc++, GCC libstdc++) объект `std::string` имеет размер 24-32 байта. 
* Если длина строки **до 15-22 символов**, она **НЕ выделяет память в куче**, а сохраняется прямо внутри самого объекта на стеке!
* Это делает короткие строки невероятно быстрыми.

## 4. `std::string_view` (C++17) и `std::span` (C++20)

Это легковесные типы-наблюдатели (**Non-owning Views**), которые состоят всего из двух полей: **[указатель, длина]** (16 байт).

### `std::string_view`:
Аналог `ReadOnlySpan<char>` в C#. Позволяет просматривать фрагменты строк без копирования и аллокаций.

```cpp
#include <iostream>
#include <string_view>

// Принимает строковые литералы "hello", std::string, char* без единой аллокации!
void PrintHeader(std::string_view header) {
    // Взятие подстроки sub.substr() тоже стоит 0 наносекунд:
    auto prefix = header.substr(0, 4);
    std::cout << "Prefix: " << prefix << "\n";
}

int main() {
    PrintHeader("POST /api/v1/users HTTP/1.1"); // Литерал: аллокаций нет!
    std::string dynamicStr = "GET /index.html";
    PrintHeader(dynamicStr);                   // std::string: копирования нет!
}
```

### `std::span<T>`:
Обобщение `string_view` на любые последовательные данные (`int[]`, `std::vector<int>`, `std::array<int, N>`):
```cpp
#include <span>
#include <vector>

void ProcessNumbers(std::span<const int> nums) {
    for (int n : nums) { /* ... */ }
}

int main() {
    int rawArray[] = { 1, 2, 3 };
    std::vector<int> vec = { 4, 5, 6 };

    ProcessNumbers(rawArray); // Работает с C-массивом
    ProcessNumbers(vec);      // Работает с вектором
}
```
