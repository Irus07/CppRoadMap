# 02. Ссылки, константность (const correctness) и constexpr

> В C++ константность — это не просто директива компилятора, это **основа безопасности и оптимизации кода**. Правильное использование `const` позволяет компилятору агрессивно оптимизировать вычисления и предотвращать 50% логических багов.

---

## 1. Разница между `const` в C++ и `readonly` / `const` в C#

* **В C#:** 
  * `const` — только для литералов, вычисляемых во время компиляции.
  * `readonly` — поле нельзя переприсвоить после конструктора (но мутировать поля внутри объекта по ссылке можно).
* **В C++:** 
  * `const` работает на **любой** переменной, параметре, методе или возвращаемом значении.
  * Означает строгую неизменяемость данных (Deep Immutability).

---

## 2. Чтение указателей с `const`: Правило «справа налево»

В C и C++ синтаксис `const` с указателями может сбить с толку. Читайте объявление **справа налево**:

```cpp
int x = 10;
int y = 20;

// 1. Указатель на константный int (Pointer to const int):
// Читаем: ptr1 - это указатель (*) на константу (const) типа int.
const int* ptr1 = &x; 
// *ptr1 = 15; // ОШИБКА: значение менять нельзя!
ptr1 = &y;     // ОК: сам указатель можно перенаправить на другой адрес.

// 2. Константный указатель (Const pointer):
// Читаем: ptr2 - это константа (const), являющаяся указателем (*) на int.
int* const ptr2 = &x;
*ptr2 = 15;    // ОК: значение по адресу можно менять!
// ptr2 = &y;  // ОШИБКА: указатель зафиксирован на адресе x навсегда.

// 3. Константный указатель на константу:
const int* const ptr3 = &x;
// Ни адрес, ни значение менять нельзя!
```

## 3. `const`-методы классов

Если метод класса не модифицирует состояние объекта, он **обязан** иметь квалификатор `const`:

```cpp
class Account {
private:
    double balance = 0.0;
public:
    // const метод: может быть вызван для любого объекта
    double GetBalance() const { 
        return balance; 
    }

    // Не-const метод: меняет состояние
    void Deposit(double amount) { 
        balance += amount; 
    }
};

void PrintAccount(const Account& acc) {
    std::cout << acc.GetBalance(); // ОК: GetBalance() помечен как const
    // acc.Deposit(100);           // ОШИБКА: нельзя вызвать не-const метод у const ссылки!
}
```

> **Ключевое слово `mutable`:** если вам нужно изменить служебное поле (например, кэш или мьютекс) внутри `const`-метода, пометьте поле как `mutable`:
> ```cpp
> mutable std::mutex mtx; // можно захватывать даже внутри const методов
> ```

## 4. `constexpr` и `consteval`: Вычисления на этапе компиляции

* `const` означает: «значение нельзя изменить во время работы программы (runtime read-only)».
* `constexpr` означает: «значение известно и может быть вычислено **во время компиляции**».
* `consteval` (C++20): «функция **обязана** выполняться исключительно во время компиляции».

### Пример:
```cpp
// Вычисляется на этапе компиляции:
constexpr int Factorial(int n) {
    return (n <= 1) ? 1 : n * Factorial(n - 1);
}

int main() {
    // Число 120 будет зашито прямо в инструкцию ассемблера!
    constexpr int val = Factorial(5); 
    
    // Можно использовать как размер массива (в C# так сделать нельзя!):
    int buffer[Factorial(4)]; // массив из 24 элементов
}
```

## 5. Структурное связывание (Structured Binding, C++17)

Аналог деконструкции кортежей (`var (id, name) = tuple;`) из C#:

```cpp
#include <tuple>
#include <string>
#include <iostream>

struct Point { double x; double y; };

Point GetPoint() { return { 10.5, 20.0 }; }

int main() {
    // Распаковка структуры:
    auto [px, py] = GetPoint();
    std::cout << "X: " << px << ", Y: " << py << "\n";

    // Распаковка пары ключ-значение в словаре:
    std::unordered_map<std::string, int> ages = { {"Alice", 25}, {"Bob", 30} };
    for (const auto& [name, age] : ages) {
        std::cout << name << " is " << age << " years old\n";
    }
}
```
